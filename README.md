# CNN实现MNIST手写数字分类
基于PyTorch手动搭建卷积神经网络（CNN），完成MNIST手写数字（0-9）分类任务，符合实验要求的网络结构设计。

## 实验要求与网络结构
| 模块         | 细节说明                                                                 |
|--------------|--------------------------------------------------------------------------|
| 输入层       | 接收MNIST灰度图，尺寸28×28×1（高度×宽度×通道数）                        |
| 特征提取     | 2个卷积块串联（卷积层+ReLU+最大池化）：<br>- 卷积层：3×3核，通道1→16→32<br>- 池化层：2×2核，尺寸28→14→7 |
| 分类部分     | 展平（32×7×7→1568维）+ 2个全连接层（1568→128→10），输出0-9分类分数      |
